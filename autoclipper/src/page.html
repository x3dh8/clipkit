Set up your auto clipper

First, register a free Twitch app so this clipper is allowed to make clips for you. It takes about 5 minutes.

  1. Open dev.twitch.tv/console/apps/create and sign in with your Twitch account. Twitch may ask you to turn on two-factor sign-in first.
  2. Name: anything unique, like clipkit-auto-yourname.
  3. OAuth Redirect URLs: http://localhost
  4. Category: Application Integration.
  5. Client Type: Public. This part matters.
  6. Tap Create, open the app with Manage, and copy the Client ID.

See what clippers post on YouTube

Shows the Shorts people are posting about your streamers: how many views they get, how fast, and which clipper channels are winning. It needs a free YouTube API key from Google (about 5 minutes).

  1. Open console.cloud.google.com, sign in, and create a project (any name).
  2. Open YouTube Data API v3 and tap Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key, and copy it.
  4. Optional but smart: tap the key, set API restrictions to YouTube Data API v3, and save.

Sending to your webhook

Get a Discord message when a clip is made, and a list of the best clips each morning. Paste a webhook link from a Discord server you manage. A private server just for you works great.

How to get a webhook link
  1. In Discord, open your server and go to Server Settings → Integrations → Webhooks.
  2. Tap New Webhook, pick the channel the messages should go to, and tap Copy Webhook URL.
  3. Paste it below.

Daily video queue

Every day, it picks the best moments, writes 3 title options, a description and hashtags for each, and suggests a time to post. It skips clips that would break YouTube rules (gambling, sexual content, slurs, promo codes, music streams) and checks every title it writes. It all lands in its own Discord channel. You review, cut the weak ones, add your take, and post.

Posting to your queue webhook

Paste the webhook link for your posts channel (Server Settings → Integrations → Webhooks → New Webhook → pick the channel → Copy Webhook URL).
